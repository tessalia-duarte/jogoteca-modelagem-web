# Jogoteca — Modelagem de Plataforma Web de Jogos Digitais

## Sobre o projeto

Projeto acadêmico desenvolvido na disciplina Projeto e Engenharia de Software do Centro Universitário UNA.

O objetivo é aplicar conceitos de Engenharia de Software e modelagem de sistemas ao planejamento de uma plataforma web que facilite a descoberta, a consulta e o acesso a jogos digitais.

## Materiais desenvolvidos

- Levantamento de requisitos funcionais e não funcionais.
- Diagrama UML de casos de uso.
- Diagrama UML de classes.
- Proposta de arquitetura cliente-servidor.
- Protótipo navegável desenvolvido no Figma.
- Artigo acadêmico sobre a modelagem da plataforma.

## Controle de versão

Este repositório será utilizado para organizar os documentos do projeto e registrar suas alterações ao longo do desenvolvimento, permitindo acompanhar a evolução dos materiais por meio do Git e do GitHub.

## Situação do projeto

O projeto encontra-se na etapa de modelagem e prototipação. Não foi realizada a implementação funcional da plataforma.
