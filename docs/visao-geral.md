# Visão geral do projeto

## Objetivo
Modelar uma plataforma web que facilite a descoberta, a consulta e o acesso a jogos digitais.

## Disciplina
Projeto e Engenharia de Software — Centro Universitário UNA.

## Situação
Projeto em fase de modelagem e prototipação, sem implementação funcional.

## Funcionalidades previstas

A plataforma foi planejada para oferecer:

- Catálogo de jogos organizado alfabeticamente.
- Pesquisa por nome ou parte do título.
- Visualização de informações dos jogos.
- Navegação entre as páginas da plataforma.
- Acesso aos jogos por meio do navegador.

Essas funcionalidades estão representadas na modelagem e no protótipo Figma, mas ainda não foram implementadas.
