
# Levantamento de requisitos

## Plataforma Web de Jogos Digitais

Os requisitos foram definidos para orientar a modelagem e a prototipação da plataforma web de jogos digitais.

Ao todo, foram identificados 11 requisitos funcionais e 5 requisitos não funcionais.

## 1. Requisitos funcionais

Os requisitos funcionais descrevem as ações e os comportamentos que o sistema deverá oferecer.

| Código | Requisito | Descrição |
|---|---|---|
| RF01 | Explorar jogos na página inicial | O sistema deve permitir que o visitante explore e selecione jogos na página inicial da plataforma, organizados em três seções: jogos em destaque, jogos mais acessados e novidades. |
| RF02 | Consultar catálogo de jogos | O sistema deve permitir que o visitante consulte o catálogo completo de jogos disponibilizados na plataforma. |
| RF03 | Ordenar jogos alfabeticamente | O sistema deve organizar automaticamente os jogos do catálogo em ordem alfabética, considerando seus títulos. |
| RF04 | Paginação do catálogo | O sistema deve apresentar até 20 jogos por página e permitir que o visitante navegue entre as páginas do catálogo. |
| RF05 | Pesquisar jogos pelo título | O sistema deve permitir que o visitante pesquise jogos por palavras ou trechos do título, apresentando os jogos cujos títulos contenham o termo pesquisado. |
| RF06 | Visualizar detalhes do jogo | O sistema deve permitir que o visitante selecione um jogo e seja direcionado à sua página de detalhes, na qual serão apresentados o título, a descrição, o gênero e a classificação etária. |
| RF07 | Acessar jogo pelo navegador | O sistema deve permitir que o visitante acesse o jogo selecionado por meio de um endereço disponibilizado na página de detalhes, possibilitando sua abertura no navegador. |
| RF08 | Registrar acessos aos jogos | O sistema deve registrar cada solicitação de acesso a um jogo, incrementando e armazenando a quantidade de acessos correspondente ao jogo selecionado. |
| RF09 | Apresentar jogos mais acessados | O sistema deve comparar as quantidades de acessos registradas para cada jogo e apresentar os jogos mais acessados em ordem decrescente de acessos, na seção correspondente da página inicial. |
| RF10 | Apresentar jogos em destaque | O sistema deve apresentar, na seção Jogos em destaque da página inicial, os jogos previamente selecionados pelos responsáveis pela plataforma. |
| RF11 | Apresentar novidades | O sistema deve identificar os jogos mais recentes com base em suas datas de inclusão e apresentá-los na seção Novidades da página inicial, em ordem decrescente de data. |

## 2. Requisitos não funcionais

Os requisitos não funcionais estabelecem as condições de qualidade e funcionamento esperadas para a plataforma.

| Código | Requisito | Descrição |
|---|---|---|
| RNF01 | Responsividade | A interface da plataforma deve adaptar-se a diferentes tamanhos de tela, incluindo computadores, tablets e smartphones, mantendo a legibilidade das informações e a facilidade de navegação. |
| RNF02 | Usabilidade | A interface da plataforma deve apresentar menus e botões de ação claramente identificados, com organização visual consistente, facilitando a navegação e a localização das funcionalidades pelo visitante. |
| RNF03 | Compatibilidade com navegadores | A plataforma deve ser compatível com versões atuais dos navegadores Google Chrome, Mozilla Firefox, Microsoft Edge e Opera, permitindo a utilização de suas principais funcionalidades e a apresentação adequada da interface. |
| RNF04 | Acessibilidade | A interface da plataforma deve permitir a navegação por teclado e ser compatível com leitores de tela, garantindo a identificação dos elementos interativos, como botões, links e campos de pesquisa. |
| RNF05 | Desempenho | A plataforma deve apresentar os resultados da pesquisa de jogos em até 10 segundos após o envio da solicitação pelo visitante. |
